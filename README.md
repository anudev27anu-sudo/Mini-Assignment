# Mini-Assignment
Tamil Nadu Electoral Analysis – 2021 & 2026

Power BI Mini Project

1. Objective

To analyse Tamil Nadu Assembly election results for 2021 and 2026, focusing on party performance, voter patterns, caste composition and electoral shifts.

2. Datasets

Election Results – 2021 and 2026

Caste Data

Voter Data – 2026

3. Data Cleaning

Standardised candidate names and constituency details.

Removed unwanted spaces using TRIM.

Replaced blank values with NILL.

Created an Actual Votes Polled column.

Combined election results with a common Year column.

4. Power BI Modelling

Created a star schema using constituency number (AC NO.).

Established table relationships.

Developed DAX calculated columns and measures.

5. Analysis and Visualisations

Party-wise seats and vote share.

Age-wise electoral performance.

NOTA votes and winning parties.

Dominant caste vs winning party (2021 and 2026).

Constituencies with shifted and retained winning parties.

6. Key Findings

Total constituencies analysed: 234.

Shifted allegiance: 71 (30.34%).

Retained allegiance: 163 (69.66%).

7. Tools

Microsoft Excel and Power BI (DAX).

8. Outcome

Developed an interactive dashboard to examine electoral performance, caste-party associations and constituency-level political transitions between 2021 and 2026.
